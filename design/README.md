# Библиотека решений

Разбор приёмов, применённых на этой странице. Каждому решению соответствует
пара файлов с одинаковым именем:

- `bad/` — как делать не стоит и почему
- `good/` — как сделано на странице

Файлы самодостаточные: открываются двойным кликом в браузере, ничего собирать
не нужно. Открывайте пару рядом в двух вкладках — разница видна сразу.

| Файл | Про что | Короткое правило |
|---|---|---|
| `01-poyavlenie` | Анимация появления при прокрутке | Ощущение «выплывания» даёт размытие, а не сдвиг |
| `02-bez-js` | Что видит посетитель, если JS не отработал | Прятать контент можно только после того, как JS подтвердил, что умеет его показать |
| `03-akcent-v-zagolovke` | Выделение смысловой части заголовка | Меняйте начертание, а не цвет |
| `04-cifry` | Порядковые номера в списках | Цифры набираются шрифтом макета, а не системным моноширинным |
| `05-ritm-sekciy` | Ритм длинной страницы | Один контрастный разворот важнее десяти оттенков |
| `06-kaskad` | Каскадное появление элементов группы | Задержка должна затухать, а не расти линейно |

## Откуда взяты приёмы

Механика движения снята с [arlo.sh](https://www.arlo.sh/) — из их таблиц стилей,
а не на глаз:

```css
--hs-ease: cubic-bezier(0.22, 1, 0.36, 1);

.hs-reveal        { opacity: 0; transform: translateY(26px); transition: .7s var(--hs-ease) }
.hs-reveal.is-in  { opacity: 1; transform: none }

@keyframes hs-rise {
  0%   { opacity: 0; transform: translateY(18px); filter: blur(7px) }
  100% { opacity: 1; transform: none;             filter: blur(0)   }
}
```

Две детали, которые легко упустить:

1. **`filter: blur(7px) → 0`.** Именно размытие создаёт впечатление, что элемент
   выплывает из глубины. Без него остаётся механический сдвиг.
2. **Наблюдение на уровне секций.** У arlo всего 7 наблюдаемых элементов на всю
   страницу; внутренние элементы догоняют каскадом через CSS-задержки. Вешать
   наблюдатель на каждый элемент — и дороже, и хуже выглядит: секция должна
   приезжать как единое целое.

## Общие принципы

**Движение служит пониманию, а не украшает.** Анимация подсказывает, что элементы
связаны и в каком порядке их читать. Если убрать её и ничего не теряется, кроме
«красиво» — она лишняя.

**Текст не двигают.** Двигать можно декор: свечения, подложки, иллюстрации.
Постоянно движущийся текст мешает читать.

**Сдержанность в амплитуде.** Сдвиг карточки под курсором на 2px читается как
отклик; на 8px — как аттракцион.

**Любую анимацию нужно уметь выключить.** `prefers-reduced-motion` — не
формальность: для части людей движение на экране вызывает физическое недомогание.

**Проверяйте состояние «до».** Самая частая ошибка анимаций появления — страница,
на которой без JS не видно ничего.
